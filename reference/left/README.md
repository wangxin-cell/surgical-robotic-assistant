# 左臂示教台

在 Windows 上解压后，双击 `Start-LeftArmTeach.cmd`。它使用系统自带的 Windows PowerShell，无需摄像头或 Python。程序按 USB 序列号 `5A7C122569` 找左臂，最近一次检出为 COM7。运行时关闭其他占用该串口的程序。

1. 点「连接并读取」，看六个关节的位置、限位和力矩。连接时只读。
2. 用稳固支撑承托臂身，夹爪空置，操作者离开活动范围，并确保现场可立即切断舵机电源。勾选检查框后点「启用保持」。工具以各关节的实测位置为目标，逐个读回力矩状态。首次真实整臂启用保持时在空旷处观察臂身。
3. 用每一行的 + 或 − 单步微调。第一次选 8 个计数，实际未见移动时观察读数，再考虑 16。表格同时显示实测位置和当前目标。进入 24 个计数的限位余量区后只能继续向内点动。舵机的配置限位不变，实测越限仍会拦截。如果上一目标与实测差距过大，底部会区分舵机仍在移动和反馈已经停住两种情况。
4. 到一个位置并稳定后，用名称例如 `A_hover`、`A_grasp`、`place_hover` 保存 JSON。导出含六个实测关节位置、限位、时间、序列号和力矩状态。左夹爪 ID 6 的已测方向是增加读数会张开，18 mm 开口的参考读数为 1572。
5. 承托住臂身后再点「支撑后释放」。关窗口或拔 USB 不会保证舵机解除力矩。异常时工具锁定新的点动操作，可能仍有部分关节保持。现场用舵机电源停机，注意臂身下坠。

v1.3 会记住每次点动的起点。如果实测沿预期方向至少走了 4 个计数、已经停稳、且距离旧目标不超过 24 个计数，可从实测位置继续向同方向走一步。如果这一步没取得进展，继续同方向加目标仍会被拦截。停稳后可用反方向键取消旧目标，第一次只将目标设为当前实测位置，第二次才会反向移动。若关节有异响、卡碰，或偏差超过 24 个计数，先支撑臂身并检查。

v1.4 在靠近限位时会把最后一步缩短到允许位置。点动诊断保存在程序目录的 `left-arm-diagnostics.jsonl`，包括下发或拦截原因、实测位置、移动状态、舵机负载原始值和供电反馈。复现时一次只点一个方向，等约两秒让软件记录反馈。

PowerShell 中运行模拟版：

```powershell
.\Start-LeftArmTeach.cmd -Simulate
```

本工具用于左臂单步示教和保存样本。导出的姿态未验证运动路径，也不包含右臂配置。参考了 [XLeRobot 开源单关节控制示例](https://github.com/Vector-Wangel/XLeRobot/blob/main/software/examples/0_so100_keyboard_joint_control.py) 的逐关节操作方式。
